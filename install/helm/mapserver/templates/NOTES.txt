OlleBo Mapserver installed as release: {{ .Release.Name }}

{{- if .Values.ingress.enabled }}

Tile server (public):
  https://{{ .Values.ingress.host }}

Make sure DNS for {{ .Values.ingress.host }} points at your Ingress controller's
external IP, and that `terracotta.publicUrl` is set to the URL above.

{{- if .Values.ingress.exposeUi }}

WARNING: ingress.exposeUi is on. The web UI has no login, so anyone who can
reach it can upload files and read the map key. Put authentication in front.
{{- else }}

The web UI is not public. Reach it with port-forward:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "mapserver.fullname" . }} 8888:{{ .Values.service.flaskPort }}
Then open http://localhost:8888
{{- end }}
{{- else }}

No Ingress was created. Reach the services with port-forward:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "mapserver.fullname" . }} 8888:{{ .Values.service.flaskPort }} 5001:{{ .Values.service.terracottaPort }}

Then open:
  Web UI:      http://localhost:8888
  Tile server: http://localhost:5001

For ollebo.com to reach this mapserver, you'll need to enable the Ingress
(--set ingress.enabled=true --set ingress.host=YOUR_DOMAIN) and set
terracotta.publicUrl to a publicly resolvable URL.
{{- end }}

{{- if not .Values.ollebo.key }}

NOTE: ollebo.key is empty. The mapserver runs fine without it. Pairing with
ollebo.com isn't built yet, so setting a key does not link the two, and the
Settings page will show Disconnected either way.
{{- end }}
